[查看我的工具](https://github.com/dstmg?tab=repositories) · [旺哥的实战项目](https://github.com/wangge-dev) · [开源 Skills 索引](https://github.com/wangge-ai/wangge-skills)

## 关于我

我关注 AI 如何进入实际的电商工作：从商品、买家反馈和竞品数据出发，先判断问题，再落实到主图、详情页、客服和经营动作。

目前主要实践三个方向：

- **电商洞察**：把评价、问大家、主图和搜索结果页，整理成有证据的优化建议。
- **经营与数据工作流**：把重复的数据整理、分析和复盘接成日常能使用的工具。
- **个人 AI 工作台**：连接知识库、阅读、内容、计划、执行记录和数据复盘。
